# DEC brand assets

Use the supplied DEC logo and partner-logo strip as official source assets; do not redraw or recreate them.

- `dec-logo.png`: use discreetly in the upper-left of the application shell/header. Keep it visually subordinate to dashboard content.
- `LOGO_STRIP_P_MED.png`: use as a very small, thin, non-interactive footer/credits strip where appropriate. It must consume minimal vertical space and must not become a dashboard banner.
- Main colors: `#3B99D4`, `#0F8F8C`, `#91C852`.
- Supporting deep navy: `#0F172A`; light neutral/mint backgrounds are appropriate.
- Use red only for critical/blocking evidence and never as the only signal.

The dashboard must look like a DEC programme analytics product, not a generic admin-template dashboard.
